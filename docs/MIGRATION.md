# Integration notes

This final app consolidates the supplied CrisisDesk and Public Infrastructure requirements into one runtime. The existing source trees are preserved outside this final app as the original reference/checkpoint. The integrated runtime carries forward their main behaviors: crisis AI triage, urgency, duplicate detection, infrastructure AI/severity, GPS/location concepts, public tracking, staff/admin workflows, donation campaigns, shelter discovery and unified administration.

The final runtime intentionally does not retain two separate frontends or two separate API servers.
